# Product Guide: Work Time Tracker

## Vision
The Work Time Tracker is a comprehensive thesis project designed to streamline attendance and communication. It consists of a robust Laravel 12 REST API backend, a modern Android application (Jetpack Compose), and a separate Vue web application.

## Target Audience
- **Employees:** The primary users who will track their daily work hours, manage leave requests, and communicate with colleagues.

## Primary Goal
To serve as a complete thesis project demonstrating a modern, full-stack work time tracking system that bridges mobile and web platforms.

## Key Features
- **GPS/QR Attendance:** Reliable clock-in validation using location data or daily rotating QR tokens.
- **Real-time Chat:** Encrypted private messaging between employees using Laravel Reverb.
- **Push Notifications:** Instant updates via Firebase Cloud Messaging (FCM) for leave requests and schedule changes.

## Security & Compliance
- **Standard Privacy:** Implements basic JWT authentication with standard role-based access control, ensuring secure but flexible user management.
