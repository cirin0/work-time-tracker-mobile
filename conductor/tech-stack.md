# Tech Stack: Work Time Tracker

## Core Backend
- **Language:** PHP 8.2+
- **Framework:** Laravel 12
- **Performance:** Laravel Octane (FrankenPHP)
- **Monitoring/Docs:** Scramble (OpenAPI), Laravel Telescope

## Database & Authentication
- **Database:** PostgreSQL 16+
- **Authentication:** JWT (php-open-source-saver/jwt-auth)

## Real-time & Communication
- **WebSockets:** Laravel Reverb (Real-time Chat)
- **Notifications:** Firebase Cloud Messaging (FCM)

## Android Mobile Application
- **Language:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Architecture:** MVVM with Clean Architecture principles
- **Dependency Injection:** Hilt
- **Networking:** Retrofit 3 + OkHttp 5
- **Local Persistence:** Room (Cache) + DataStore (Preferences)
- **Hardware Integrations:** CameraX + ML Kit (QR Scanning), Play Services Location (GPS)
